# Arrhythmia Dataset

## Download Instructions

1. Go to: https://archive.ics.uci.edu/ml/machine-learning-databases/arrhythmia/
2. Download `arrhythmia.data`
3. Save in this folder

## Expected File
- **Filename:** arrhythmia.data
- **Size:** ~96 KB
- **Records:** 452 patients

## Dataset Information
- Contains ECG measurements for arrhythmia classification
- 279 features total (we use first 9 for consistency)
- Target: 1 = Normal, 2-16 = Various arrhythmia types
